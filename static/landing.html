A secret key is visible in the website's code

Why it matters

Everything a website sends to the browser can be read by anyone, so this key is public. Attackers can use it to run up bills or reach your data.

What to do

Revoke and replace the key now, then move the call that needs it into a server-side function (for example an API route or edge function). Only keys meant to be public belong in the browser.

📋 Paste this into your AI tool: Please fix this problem in my website: a secret key is visible in the website's code (app.js, line 3). Move the call that needs it into a server-side function and load the key from an environment variable there.

Questions

I'm not a developer. Will I understand the results?

Yes. Every problem is explained in everyday words: what it is, what could happen, and what to do. You can also copy the fix and paste it straight into the AI tool you built with.

Does it work with Lovable, Bolt, Cursor or Replit?

Yes. VibeGuard checks what you ship: your Android app file, your live website, or your project's code. It doesn't matter which tool wrote it.

Do I have to upload my code?

No. The free check and the $9 report only need your app file or your website's address. You only upload your code if you want us to fix things for you.

Is it safe to upload my app or code?

Uploads are deleted after 24 hours, and secret files such as signing keys and .env files are never kept. You can only check apps and websites you own or have permission to test.

What if it finds something serious?

Start with the items marked "Fix right away". The report tells you exactly what to do, or choose Bug fixing and we fix it in your code for you. Every fix is checked again before you get it.

Will the fixes break my app?

Every fix is checked again before you get it, and fixes that could break other parts of your app are rejected. We can't run your app, so try it once before you publish; the report reminds you.
